# ✅ `**&p` 타입

네 풀이:

```
p      → int*
&p     → int**
*&p    → int*
**&p   → int
```

✔️ **정답 맞다.**

왜냐하면:

```
*&p == p
```

즉

```
**&p == *p == int
```

완벽 👍

---

이제 요청한 4개를 **메모리 그림 포함해서 깊게 정리**해줄게.

---

# 🔥 1️⃣ 배열과 포인터의 진짜 차이

이게 C에서 가장 많이 오해되는 부분.

---

## 선언 비교

```c
int arr[3];
int *p;
```

### 타입 차이

| 항목     | 배열              | 포인터             |
| ------ | --------------- | --------------- |
| 타입     | int[3]          | int*            |
| 크기     | 12 bytes (3×4)  | 8 bytes (64bit) |
| 변경 가능? | ❌ arr = 다른주소 불가 | ✅ p = 다른주소 가능   |

---

## 🔬 메모리 그림

```c
int arr[3] = {10,20,30};
int *p = arr;
```

```
주소      값
--------------------
0x1000    10   ← arr[0]
0x1004    20   ← arr[1]
0x1008    30   ← arr[2]

0x2000    0x1000  ← p
```

### 핵심

* 배열은 **데이터 자체**
* 포인터는 **주소만 저장**

---

## 🔥 중요한 차이

```c
arr = p;   // ❌ 불가능 (배열은 대입 불가)
p = arr;   // ✅ 가능
```

배열은 "고정된 메모리 블록 이름"이기 때문.

---

# 🔥 2️⃣ &arr vs arr 차이 (메모리 레벨)

이건 진짜 핵심.

```c
int arr[3] = {10,20,30};
```

---

## 타입

```
arr      → int[3]
&arr     → int (*)[3]
```

---

## 메모리

```
0x1000  10
0x1004  20
0x1008  30
```

---

## 주소 비교

```
arr    = 0x1000
&arr   = 0x1000
```

주소 값은 같아 보인다.

하지만 타입이 다르다.

---

## 🔥 차이는 포인터 산술에서 드러남

```c
arr + 1
```

→ int 한 칸 이동
→ 0x1004

```c
&arr + 1
```

→ 배열 전체 크기만큼 이동
→ 0x1000 + sizeof(int[3])
→ 0x1000 + 12
→ 0x100C

```

---

### 그림

```

arr      ──► [10][20][30]
arr+1    ──►     [20]

&arr     ──► [10][20][30]
&arr+1   ──►               (배열 전체 다음)

````

---

# 🔥 3️⃣ sizeof(arr) vs sizeof(&arr[0])

같은 예제:

```c
int arr[3];
````

---

## 결과

```
sizeof(arr)        = 12
sizeof(&arr[0])    = 8   (64bit 기준)
```

---

## 이유

| 표현      | 의미    |
| ------- | ----- |
| arr     | 배열 전체 |
| &arr[0] | int*  |

---

## 중요한 규칙

배열은 함수 인자로 전달되면 포인터로 decay됨:

```c
void f(int arr[])   // 실제는 int*
```

그래서

```c
void f(int arr[]) {
    sizeof(arr);  // 8 (포인터 크기)
}
```

---

# 🔥 4️⃣ 포인터 산술(pointer arithmetic)

이건 타입이 전부다.

---

## 예제

```c
int arr[3] = {10,20,30};
int *p = arr;
```

---

## 메모리

```
0x1000  10
0x1004  20
0x1008  30
```

---

## 연산

```
p       = 0x1000
p + 1   = 0x1004
p + 2   = 0x1008
```

왜?

```
p + n  =  p + n * sizeof(int)
```

---

## char는 다름

```c
char arr[3];
```

```
arr+1  = 1바이트 이동
```

---

## 구조체 예제

```c
struct A { int x; double y; };  // 보통 16 bytes
struct A arr[2];
```

```
arr+1  = 16 bytes 이동
```

---

# 🔥 핵심 공식 요약

```
포인터 + n  →  n * sizeof(가리키는 타입) 만큼 이동
```

---

# 🎯 전체 정리

### 1. 배열은 데이터, 포인터는 주소

### 2. arr ≠ &arr

* 값은 같아보여도 타입이 다름
* 산술 결과 다름

### 3. sizeof(arr) 는 배열 전체 크기

### 4. sizeof(&arr[0]) 는 포인터 크기

### 5. 포인터 산술은 타입 크기 기반 이동
