---

# 🔥 0단계: 기본 타입부터

```c
char c;
```

```
c         → char
&c        → char*
```

---

# 🔥 1단계: 문자열

```c
char *s = "Java";
```

```
s         → char*
&s        → char**
```

왜?

* s는 "문자 하나가 아니라 문자열 시작 주소"
* 그래서 `char*`
* 그 주소를 또 가리키면 `char**`

---

# 🔥 2단계: 문자열 배열

```c
char *arr[] = {"Java", "C++"};
```

### 타입 정리

```
arr           → char*[]        (char*의 배열)
arr[0]        → char*
&arr[0]       → char**
```

여기까지 이해되면 90% 성공.

---

# 🔥 3단계: qsort에서 넘어오는 a의 실제 정체

```c
int cmp(const void* a, const void* b)
```

여기서 우리가 정렬하는 건:

```c
qsort(arr, n, sizeof(char*), cmp);
```

원소 타입은:

```
char*
```

그럼 qsort는 comparator에 뭘 넘기냐?

```
원소의 주소
```

즉:

```
&arr[i]
```

그 타입은?

```
char**
```

---

# 🔥 4단계: 이제 핵심 줄

```c
*(char**)a
```

분해해보자.

---

## 1️⃣ `(char**)a`

"void*인 a를 char**라고 해석"

즉:

```
a를 char**로 본다
```

---

## 2️⃣ `*(char**)a`

그 char**를 한 번 역참조

```
*(char**)a
```

이건:

```
char*
```

왜냐하면

```
char** → 역참조 → char*
```

---

# 🔬 완전 메모리 그림

```
arr:

주소      값
0x1000 → 0x5000   (arr[0] = "Java")
0x1008 → 0x5010   (arr[1] = "C++")
```

qsort가 cmp에 넘기는 a:

```
a = 0x1000
```

이걸 캐스팅:

```
(char**)a = 0x1000  (char**라고 믿음)
```

역참조:

```
*(char**)a
= *(0x1000)
= 0x5000
```

0x5000은 문자열 시작 주소

타입은?

```
char*
```

---

# 🔥 그래서 결론

```
*(char**)a  → char*
```

절대 char**가 아니다.

---

# 🔥 왜 네가 헷갈렸냐면

여기서 착각 포인트는 이거야:

```
a는 char**인가?
```

정답:

```
a는 void*이고
실제로는 char** 값이 들어있다
```

근데

```
*(char**)a
```

하면 한 번 벗겨지니까 char*가 되는 것.

---

# 🎯 포인터 단계 공식

```
T      → 변수
T*     → &T
T**    → &(T*)
```

그리고

```
*T*  → T
*T** → T*
```
