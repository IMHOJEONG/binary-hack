이 코드는 `S` 배열 자체를 직접 보는 게 아니라, 먼저 **증가/감소 방향**으로 바꾼 다음, 그 방향이 **얼마나 길게 “번갈아(증가↔감소)” 나오느냐**를 구하려는 코드야. (일종의 *wiggle / 지그재그* 길이)

다만 구현이 좀 꼬여 있어서 “정확히 뭘 세는지”와 “버그/누수”를 같이 짚어줄게.

---

## 1) 각 함수가 하는 일

### `func_b(S)`

```c
ret[0] = -1;
for i=1..:
  if S[i] > S[i-1] ret[i]=INC(0)
  else if S[i] < S[i-1] ret[i]=DEC(1)
  // 같으면 ret[i]를 안 채움(⚠️)
```

* 원본 수열을 `INC/DEC` 방향 배열로 변환해.
* 즉 `check[i]`는 “i-1 → i로 갈 때 증가냐 감소냐”를 나타냄.
* 예: `S = [2,5,7,3]`이면

  * 2→5 증가(INC)
  * 5→7 증가(INC)
  * 7→3 감소(DEC)
    → check = [-1, INC, INC, DEC]

⚠️ 문제: `S[i] == S[i-1]`이면 `ret[i]`를 **아예 대입하지 않아서 쓰레기 값**이 남음(UB).

---

### `func_a(check)`

```c
ret[0]=1;
for i=1..:
  if check[i] != check[i-1] ret[i] = ret[i-1]+1;
  else ret[i]=2;
```

* 방향 배열에서 **연속해서 값이 바뀌는 길이**를 누적하려는 시도야.
* `check[i] != check[i-1]` 이면 “방향이 바뀜(지그재그)”이라 길이 +1
* 같으면 “지그재그가 끊김”이라 2로 리셋 (이건 “최소 길이=2”라는 가정)

---

### `func_c(dp)`

```c
max를 구함
if max == 2 return 0;
else return max;
```

* dp에서 최댓값을 반환하되, 최댓값이 2면 의미 없다고 보고 0으로 돌려줌.

  * 즉 “지그재그 길이가 2밖에 안 되면 0으로 치겠다”는 규칙

---

## 2) 전체적으로 무엇을 구하나?

정리하면:

1. `S`에서 “증가/감소 방향”을 만든다 (`func_b`)
2. 그 방향이 **얼마나 길게 INC/DEC가 번갈아 나오나**를 센다 (`func_a`)
3. 그 최대 길이를 반환하되, 최대가 2뿐이면 0 (`func_c`)

즉, **연속 구간에서 증가/감소가 번갈아 나타나는 최대 길이** (단, 길이 2는 무시)

---

## 3) 주어진 3개 입력에 대해 실제 결과(이 코드 의도 기준)

### S1 = {2,5,7,3,4,6,1,8,9}

방향(>,<):

* 2→5 ↑
* 5→7 ↑
* 7→3 ↓
* 3→4 ↑
* 4→6 ↑
* 6→1 ↓
* 1→8 ↑
* 8→9 ↑

INC/DEC로 보면:
`↑ ↑ ↓ ↑ ↑ ↓ ↑ ↑`

여기서 가장 긴 “번갈아” 구간은
`↑ ↓ ↑` (길이 3) 또는 `↓ ↑ ↓ ↑` 같은 식으로 최대 **3** 정도가 나와.
(연속된 ↑↑ 때문에 자주 끊김)

→ 답은 **3**

---

### S2 = {4,3,2,1,10,6,9,7,8}

방향:
`↓ ↓ ↓ ↑ ↓ ↑ ↓ ↑`

여기서는 `↑ ↓ ↑ ↓ ↑` 같은 번갈아가 비교적 길게 나오므로 최대가 **5**가 됨.

→ 답은 **5**

---

### S3 = {1,2,3,4,5}

방향:
`↑ ↑ ↑ ↑`

번갈아가 전혀 없음 → dp 최대는 2로만 유지 → `func_c`가 0 반환

→ 답은 **0**

---

## 4) 코드의 치명적 문제점들

### ✅ (1) 메모리 누수

`func_a`, `func_b`에서 malloc한 배열을 `solution`에서 free 안 함.

### ✅ (2) `func_b`에서 “같은 값” 처리 안 해서 UB

`S[i] == S[i-1]`이면 `ret[i]`가 초기화되지 않음 → 이후 비교가 쓰레기 값과 비교됨.

### ✅ (3) `ret[i]=2` 리셋 로직이 애매

“방향이 같으면 2”로 리셋하는 게 항상 맞지는 않아.
wiggle 문제 정석은 “같은 방향이면 길이 유지하거나, 마지막 값을 갱신” 등 다른 처리가 필요할 때가 많음.

---

## 5) 안전하게 최소 수정(UB + 누수 해결) 버전

* `func_b`에서 같으면 “이전과 같은 방향으로 처리”하거나 “특별 값”을 넣어야 함.
* 여기서는 가장 간단히 **같으면 이전 방향 유지**로 처리해볼게(지그재그에는 도움 안 되지만 UB는 막음).

```c
int* func_b(int arr[], int arr_len){
    int* ret = (int*)malloc(sizeof(int)*arr_len);
    ret[0] = -1;
    for(int i = 1; i < arr_len; i++){
        if(arr[i] > arr[i-1]) ret[i] = INC;
        else if(arr[i] < arr[i-1]) ret[i] = DEC;
        else ret[i] = ret[i-1]; // ✅ UB 방지: 같으면 이전 방향 유지
    }
    return ret;
}

int solution(int S[], int S_len) {
    int* check = func_b(S, S_len);
    int* dp = func_a(check, S_len);
    int answer = func_c(dp, S_len);

    free(check);
    free(dp);
    return answer;
}
```

---

원래 이게 “wiggle subsequence(부분수열)” 문제야, 아니면 “연속 구간(subarray)” 문제야?
지금 코드는 **연속 구간** 기준으로만 세는 형태라서, 문제 의도가 “부분수열”이면 정석 DP/그리디로 완전히 다른 풀이가 필요해.
