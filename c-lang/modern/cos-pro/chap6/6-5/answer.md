이 코드는 **4×4 보드에서 (0,0)에서 (3,3)까지 “오른쪽/아래로만” 이동할 때 얻을 수 있는 최대 코인 합**을 구하는 **DP(동적 계획법)** 예제야. (전형적인 “최대 경로 합”)

---

## 핵심 아이디어

`coins[i][j]`를 이렇게 정의해:

> **(0,0) → (i,j)** 까지 올 때 얻을 수 있는 **최대 누적 합**

그럼 (i,j)에 도착하는 방법은 딱 두 가지뿐이야:

* 위에서 내려오기: `(i-1, j) → (i, j)`
* 왼쪽에서 오기: `(i, j-1) → (i, j)`

따라서 점화식은:

[
coins[i][j] = board[i][j] + \max(coins[i-1][j],\ coins[i][j-1])
]

(단, 첫 행/첫 열은 한 방향밖에 없어서 누적합으로 처리)

---

## 코드가 케이스별로 나눈 이유

```c
if(i == 0 && j == 0)                  // 시작점
else if(i == 0 && j != 0)             // 첫 행: 왼쪽에서만 옴
else if(i != 0 && j == 0)             // 첫 열: 위에서만 옴
else                                  // 나머지: 위/왼쪽 중 큰 값 선택
```

## 주어진 입력에서 실제 DP 테이블 계산

보드 `board`:

```
6 7 1 2
3 5 3 9
6 4 5 2
7 3 2 6
```

`coins`를 채우면:

### 0행 (첫 행은 왼쪽 누적)

* (0,0)=6
* (0,1)=6+7=13
* (0,2)=13+1=14
* (0,3)=14+2=16

→ `coins[0] = [6, 13, 14, 16]`

### 1행

* (1,0)=6+3=9
* (1,1)=5 + max(13,9)=18
* (1,2)=3 + max(14,18)=21
* (1,3)=9 + max(16,21)=30

→ `coins[1] = [9, 18, 21, 30]`

### 2행

* (2,0)=9+6=15
* (2,1)=4 + max(18,15)=22
* (2,2)=5 + max(21,22)=27
* (2,3)=2 + max(30,27)=32

→ `coins[2] = [15, 22, 27, 32]`

### 3행

* (3,0)=15+7=22
* (3,1)=3 + max(22,22)=25
* (3,2)=2 + max(27,25)=29
* (3,3)=6 + max(32,29)=38

→ `coins[3] = [22, 25, 29, 38]`

그래서 최종 답:

```c
answer = coins[3][3]; // 38
```

✅ 출력은:

```
solution 함수의 반환 값은 38 입니다.
```

## 시간/공간 복잡도

* 시간: O(4×4) = O(1) (고정 크기)
* 공간: O(4×4)
