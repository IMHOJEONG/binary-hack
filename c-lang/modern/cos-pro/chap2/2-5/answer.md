지금 코드의 문제는:

* `max(nextV, nowV)`는 **값의 최대값**만 구하고 있고
* 우리가 원하는 건 **연속해서 증가하는 부분 배열의 “길이”**임
* 이건 이중 for문으로 풀 문제가 아니라, 한 번만 순회하면 됨 (O(n))

---

## 🎯 문제 정의

예:

```
[1, 2, 3, 2, 3, 4, 5, 1]
```

연속 증가 구간:

* 1,2,3 → 길이 3
* 2,3,4,5 → 길이 4  ← 정답

👉 결과: `4`

---

# ✅ 올바른 접근 (O(n))

핵심 아이디어:

* 현재 증가 길이 `current`
* 최대 길이 `maxLen`
* 이전 값보다 크면 증가
* 아니면 길이 리셋

---

## ✨ 깔끔한 정답 코드

```c
int solution(int arr[], int arr_len) {
    if (arr_len == 0) return 0;

    int maxLen = 1;
    int current = 1;

    for (int i = 1; i < arr_len; i++) {
        if (arr[i] > arr[i - 1]) {
            current++;
        } else {
            current = 1;
        }

        if (current > maxLen) {
            maxLen = current;
        }
    }

    return maxLen;
}
```

---

## 🔎 동작 원리

| 상황     | current | maxLen |
| ------ | ------- | ------ |
| 증가하면   | +1      | 갱신     |
| 증가 끊기면 | 1로 초기화  | 유지     |

## ⚠️ 지금 코드가 잘못된 이유

```c
answer = max(nextV, nowV);
```

* 값 비교만 함
* 길이를 세지 않음
* 마지막 루프 값으로 덮어쓰기 됨

그리고 `max()`는 C 기본 함수가 아님
직접 정의해야 함:

```c
#define max(a,b) ((a) > (b) ? (a) : (b))
```

## 🧠 확장 문제

1. 가장 긴 증가 구간의 시작 index 구하기
2. 실제 증가 부분 배열 반환하기
3. 감소 구간도 포함한 바이토닉 구간 구하기

원하면 거기까지 확장해줄까?

---


주어진 배열:

```
{3, 1, 2, 4, 5, 1, 2, 2, 3, 4}
```

우리가 구하는 것은 👉 **연속해서 증가하는 가장 긴 부분 배열의 길이**

---

## 🔎 구간별 분석

### 1️⃣ 시작: `3`

* 다음 값 `1` → 감소
  → 길이 = 1

---

### 2️⃣ `1, 2, 4, 5`

* 1 < 2 ✔
* 2 < 4 ✔
* 4 < 5 ✔
  → 길이 = **4**

---

### 3️⃣ `1, 2`

* 1 < 2 ✔
  → 길이 = 2
  다음 `2`는 증가 아님 (2 == 2 ❌)

---

### 4️⃣ `2, 3, 4`

* 2 < 3 ✔
* 3 < 4 ✔
  → 길이 = 3

---

# ✅ 최종 정답

가장 긴 증가 구간은:

```
1, 2, 4, 5
```

👉 **길이 = 4**
