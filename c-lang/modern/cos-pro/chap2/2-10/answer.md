이 코드는 문자열 `s`에서

* `'1'`은 모두 유지
* `'0'`은 **연속된 0 중 마지막 0만 남기고 제거**

하는 로직이야.

---

## 🔎 코드 동작 예시

### 입력

```
"00011000100"
```

### 처리 과정

* `'1'` → 그대로 추가
* `'0'` → 다음이 `'0'`이면 skip
* `'0'` → 다음이 `'0'`이 아니면 추가

### 결과

```
"0110100"
```

(연속 0 덩어리마다 하나만 남음)

---

# ⚠️ 중요한 버그 ⚠️

```c
if (s[i] == '0' && s[i+1] != '0')
```

💥 **마지막 문자에서 s[i+1] 접근하면 위험함**

문자열 끝에서는 `s[length]` 접근하게 됨 → UB (Undefined Behavior)

---

# ✅ 안전한 수정 버전

```c
#include <stdlib.h>
#include <string.h>

char* solution(const char* s) {
    int length = strlen(s);
    char* answer = (char*)malloc(length + 1);  // 최대 길이만큼만 필요
    if (!answer) return NULL;

    int idx = 0;

    for (int i = 0; i < length; ++i) {
        if (s[i] == '1') {
            answer[idx++] = '1';
        }
        else if (s[i] == '0') {
            // 마지막 문자이거나 다음 문자가 0이 아닐 때만 추가
            if (i == length - 1 || s[i + 1] != '0') {
                answer[idx++] = '0';
            }
        }
    }

    answer[idx] = '\0';
    return answer;
}
```

---

# 📌 메모리도 개선됨

기존 코드:

```
malloc(sizeof(char) * 1001)
```

→ 입력이 10글자여도 1001바이트 할당 (비효율)

수정 코드:

```
malloc(length + 1)
```

→ 정확한 크기
