이 코드는 `walls[i] = {x좌표, 높이}`라고 할 때, 두 벽을 골라서

* 가로 길이 = `x[j] - x[i]`
* 세로 높이 = `min(h[i], h[j])`

로 만드는 “직사각형(컨테이너)”의 **최대 면적**을 구하는 코드야.
(완전 똑같이 “Container With Most Water” 문제)

---

## 코드가 하는 일 (라인 기준)

### 1) 모든 쌍 (i, j) 탐색

```c
for (int i = 0; i < walls_len; i++)
  for (int j = i+1; j < walls_len; j++)
```

→ 가능한 두 벽 조합을 전부 봄 (O(n²))

### 2) 면적 계산

```c
if (walls[i][1] < walls[j][1])
    area = walls[i][1] * (walls[j][0] - walls[i][0]);
else
    area = walls[j][1] * (walls[j][0] - walls[i][0]);
```

이게 사실상:

```c
area = min(h[i], h[j]) * (x[j] - x[i]);
```

### 3) 최대값 갱신

```c
if (answer < area) answer = area;
```

---

## 주어진 입력의 결과는?

입력:

```
(1,4), (2,6), (3,5), (5,3), (6,2)
```

주요 조합들 면적:

* (1,4) & (6,2) → min=2, width=5 → 10
* (2,6) & (6,2) → min=2, width=4 → 8
* (1,4) & (5,3) → min=3, width=4 → 12 ✅
* (2,6) & (5,3) → min=3, width=3 → 9
* (3,5) & (6,2) → min=2, width=3 → 6
* (2,6) & (3,5) → min=5, width=1 → 5

최대는 **12** (x=1 높이4, x=5 높이3)

따라서 출력:

```
solution 함수의 반환 값은 12 입니다.
```

---

## 중요한 전제/주의점

### 1) `walls[j][0] - walls[i][0]`가 양수여야 함

코드는 `j > i`이기만 하고, x가 정렬되어 있다는 보장은 없음.
만약 x가 섞여 있으면 width가 음수가 될 수 있어.

➡️ 안전하게 하려면:

* 입력이 x 오름차순이라는 전제가 필요하거나
* width에 `abs`를 쓰거나
* 아예 x 기준으로 정렬 후 처리해야 함

### 2) 시간복잡도 O(n²)

n이 커지면 느림. 이 문제는 원래 **two pointers로 O(n)** 정답 가능.

---

## (원하면) O(n) 투포인터 정답도 가능

* 왼쪽/오른쪽 끝에서 시작
* 면적 계산 후
* 더 낮은 높이 쪽 포인터를 안쪽으로 이동

원하면 네 입력 포맷 `{x, h}` 유지한 채로 투포인터 버전도 만들어줄게.
