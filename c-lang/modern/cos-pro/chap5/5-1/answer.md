# 📌 이 코드가 푸는 문제

> 한 번에 1칸, 2칸, 3칸씩 오를 수 있을 때
> n칸을 오르는 방법의 수는?

---

## 🧠 점화식 원리

n번째 계단에 도달하려면:

* (n-1)에서 1칸 올라오거나
* (n-2)에서 2칸 올라오거나
* (n-3)에서 3칸 올라와야 함

따라서:

[
steps[n] = steps[n-1] + steps[n-2] + steps[n-3]
]

---

# 📌 초기값

```c
steps[1] = 1;
steps[2] = 2;
steps[3] = 4;
```

왜?

### n=1

* (1)
  → 1가지

### n=2

* (1+1)
* (2)
  → 2가지

### n=3

* (1+1+1)
* (1+2)
* (2+1)
* (3)
  → 4가지

---

# 📌 예시 실행

## n=3

이미 초기값:

```
steps[3] = 4
```

출력:

```
4
```

---

## n=4

```
steps[4] =
  steps[3] +
  steps[2] +
  steps[1]
= 4 + 2 + 1
= 7
```

출력:

```
7
```

---

# 📌 시간복잡도

* O(n)
* 매우 효율적

---

# ⚠️ 문제점 (중요)

### ❌ 1. n이 1,2,3보다 작은 경우 터짐

```c
steps[2] = 2;
steps[3] = 4;
```

n이 1이면
→ steps[2], steps[3] 접근 시 UB

---

### ❌ 2. 메모리 해제 안 함

malloc 했는데 free 없음

---

### ❌ 3. 굳이 배열 필요 없음

이건 이전 3개 값만 필요하므로
O(1) 공간으로 가능

---

# ✅ 안전한 수정 버전

```c
int solution(int n) {
    if (n == 1) return 1;
    if (n == 2) return 2;
    if (n == 3) return 4;

    int a = 1, b = 2, c = 4;
    int next;

    for (int i = 4; i <= n; i++) {
        next = a + b + c;
        a = b;
        b = c;
        c = next;
    }

    return c;
}
```

✔ 메모리 사용 없음
✔ 더 안전
✔ 더 깔끔
