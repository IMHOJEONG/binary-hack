## 1번 피드백 ✅

```c
int *p = malloc(sizeof(int));
*p = 100;

printf("%d", *p);
free(p);
```

### 개선 포인트

* `malloc` 실패 체크 (실전 습관)
* `main`은 보통 `return 0;`로 끝내기

```c
int *p = malloc(sizeof(int));
if (!p) return 1;
...
free(p);
return 0;
```

## 2번 피드백 ✅

배열 할당/접근/해제 다 정상.

### 개선 포인트

* 출력할 때 구분자(공백/줄바꿈) 넣는 게 디버깅에 좋음

printf("%d ", p[i]);

* 역시 `malloc` 체크 습관

## 3번 피드백 ⚠️ (여기만 “반드시” 수정)

코드가 거의 완벽한데, **딱 2가지 빠졌어.**

### ① `free(p)`가 없음 (메모리 누수)

코테에선 큰 문제 아닐 수 있지만 습관화해야 함.

### ② `malloc` 실패 체크 + n 검증

`n<=0`이면 `malloc(0)` 같은 케이스도 생김.

✅ 추천 수정 버전:

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int n;
    if (scanf("%d", &n) != 1 || n <= 0) return 1;

    int *p = malloc(sizeof(int) * n);
    if (!p) return 1;

    for (int i = 0; i < n; i++) {
        p[i] = i * 10;
        printf("%d\n", p[i]);
    }

    free(p);
    return 0;
}
```

## ✅ 4번: `p[i]` vs `*(p+i)` 실험 문제

**문제:** n을 입력받고 (n<=20 정도), 배열 만들고 값을 채운 뒤
두 방식으로 같은 값이 출력되는지 보여줘.

**요구사항**

* `p[i]`로 한 번 출력
* `*(p+i)`로 한 번 출력
* 그리고 `printf("%p")`로 주소도 같이 출력 (포인터 감각 핵심)

원하는 출력 예:

```
i=0  p[i]=0   *(p+i)=0   &p[i]=0x...
i=1  p[i]=10  *(p+i)=10  &p[i]=0x...
...
```
