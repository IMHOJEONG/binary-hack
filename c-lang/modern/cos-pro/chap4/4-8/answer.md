이 코드는

* `card[]`에 있는 숫자들로 만들 수 있는 **중복 없는 모든 순열(perm)** 을
* **사전순(lexicographic)** 으로 나열했을 때
* 숫자로 합친 값이 `n`이 되는 순열이 **몇 번째(1부터)** 인지 찾는 코드야.
  없으면 `-1`.

(정확히는 `qsort`로 정렬한 뒤, DFS로 앞자리부터 작은 숫자부터 채우는 방식이라 사전순이 맞아.)

---

## 코드 흐름 핵심

### 1) 정렬

```c
qsort(cardbox, card_len, sizeof(int), cmp);
```

→ 순열을 사전순으로 만들기 위한 준비.

### 2) 순열 생성 + 중복 제거

```c
if (i > 0 && card[i] == card[i-1] && !isVisited[i-1]) continue;
```

이 조건이 핵심이야.

* 같은 값이 연속으로 있을 때,
* “앞의 동일 값( i-1 )을 아직 안 썼으면”
* 지금 값(i)을 쓰지 않는다

→ 같은 숫자들로 인해 생기는 **중복 순열**을 제거하는 표준 패턴.

### 3) 완성된 순열마다 order 증가

```c
(*order)++;
int value = toInt(result, len);
if (value == n) *answer = *order;
```

* `order`는 “지금까지 나온 (중복 제거된) 순열의 개수” = 곧 “몇 번째인지”
* 찾으면 `answer`에 저장하고, 이후엔 `if (*answer != -1) return;`로 조기 종료.

## 주어진 main()의 결과

### 케이스 1

```c
card = {1,2,1,3}  → 정렬하면 [1,1,2,3]
n = 1312
```

[1,1,2,3]의 중복 없는 순열을 사전순으로 나열하면:

1. 1123
2. 1132
3. 1213
4. 1231
5. 1312  ✅

따라서 반환값은 **5**

---

### 케이스 2

```c
card = {1,1,1,2}
n = 1122
```

이 카드로 만들 수 있는 숫자는 2가 1개뿐이라 **1122는 만들 수 없음**.
가능한 순열은:

* 1112
* 1121
* 1211
* 2111

그래서 반환값은 **-1**

## 짧은 개선 포인트(안전성)

* `cmp`는 큰 수에서 overflow 위험이 있으니 비교를 이렇게 쓰는 게 안전함:

```c
int cmp(const void* a, const void* b) {
  int x = *(const int*)a, y = *(const int*)b;
  return (x > y) - (x < y);
}
```

* `toInt`는 자릿수가 커지면 int overflow 가능 → 필요하면 `long long`로.

원하면 “n이 몇 번째인지”를 DFS로 직접 세지 말고, 조합론으로 바로 계산해서 더 빠르게 찾는 방법도 알려줄게.
