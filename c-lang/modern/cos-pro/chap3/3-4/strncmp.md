좋은 질문 👍
`strncmp`는 **두 문자열을 “앞에서부터 최대 n글자까지만” 비교하는 함수**야.

---

# ✅ 기본 형태

```c
int strncmp(const char* s1, const char* s2, size_t n);
```

📌 `<string.h>` 에 정의되어 있음.

---

# ✅ 동작 방식

* `s1`과 `s2`를 앞에서부터 비교
* 최대 `n`글자까지만 비교
* 다른 문자가 나오면 거기서 멈춤
* 또는 `'\0'`(문자열 끝) 만나면 멈춤

---

# ✅ 반환값 의미

| 결과 | 의미              |
| -- | --------------- |
| 0  | 두 문자열이 n글자까지 동일 |
| 음수 | s1 < s2         |
| 양수 | s1 > s2         |

정확히는:

```c
(unsigned char)s1[i] - (unsigned char)s2[i]
```

---

# ✅ 예시

```c
strncmp("abc", "abd", 3);
```

→ 'c' - 'd' = 음수
→ 음수 반환

---

```c
strncmp("abcdef", "abcxyz", 3);
```

→ 앞 3글자 동일
→ 0 반환

---

```c
strncmp("abc", "abcd", 4);
```

→ 4번째 비교에서 '\0' vs 'd'
→ 음수 반환

---

# ✅ `strcmp`와 차이

| 함수      | 비교 범위     |
| ------- | --------- |
| strcmp  | 문자열 끝까지   |
| strncmp | 최대 n글자까지만 |

---

# 🔎 네 코드에서 쓰인 의미

```c
strncmp(a + lenA - k, b, k)
```

→ `a`의 끝에서 k글자
→ `b`의 앞에서 k글자
→ 같은지 비교

즉, “suffix == prefix” 검사하는 거야.

---

# ⚠️ 주의점

`strncmp`는 **길이 체크 안 해도 안전**함.
왜냐면 문자열 끝 `\0`에서 멈추기 때문.

하지만:

```c
strncmp(ptr, ptr2, 큰값)
```

에서 두 문자열 중 하나가 짧으면 `\0` 비교가 발생함.
