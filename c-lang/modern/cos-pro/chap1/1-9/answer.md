이 코드는 `recordA`와 `recordB`를 같은 길이로 두고, 각 인덱스마다 값을 비교해서 **점수(cnt)를 누적/감소**시키는 로직이야.
(값 0/1/2를 “가위바위보” 같은 3상태로 해석하는 형태에 가깝고, `func()`는 특정 관계(이김/짐)를 나타내는 매핑처럼 쓰이고 있어.)

아래에 **한 줄씩 + 전체 흐름**을 설명할게.

---

## 1) func 함수

```c
int func(int record){
    if(record == 0) return 1;
    else if(record == 1) return 2;
    return 0;
}
```

* 입력 `record`가

  * 0이면 1 반환
  * 1이면 2 반환
  * 그 외(사실상 2라고 가정)면 0 반환
* 즉 순환 매핑:

| 입력 | 출력 |
| -- | -- |
| 0  | 1  |
| 1  | 2  |
| 2  | 0  |

이건 “다음 것”으로 한 칸 밀어주는 순환 함수야. (0→1→2→0)

#### 2-1) 값이 같으면 아무 일도 안 함

```c
        if(recordA[i] == recordB[i])
            continue;
```

* A와 B가 같은 값이면 점수 변화 없음.
* `continue`로 다음 i로 넘어감.

---

#### 2-2) 특정 관계면 +3점

```c
        else if(recordA[i] == func(recordB[i]))
            cnt = cnt + 3;
```

* `func(recordB[i])`는 B값을 0→1→2→0으로 바꾼 값.
* 만약 `recordA[i]`가 그 값과 같다면 `cnt += 3`

즉, A와 B가 다를 때 **A가 B의 “다음 값”이면** +3점.

예시:

* B=0이면 func(B)=1 → A가 1이면 +3
* B=1이면 func(B)=2 → A가 2이면 +3
* B=2이면 func(B)=0 → A가 0이면 +3

---

#### 2-3) 그 외에는 -1점(단, 0 밑으로는 안 내려감)

```c
        else
            cnt = cnt == 0 ? 0 : cnt - 1;
```

* 위 두 조건(같음 / +3 조건) 모두 아니면 여기로 옴.
* cnt가 0이면 그대로 0 유지
* 0이 아니면 1 감소

즉, **실패 패널티 -1**인데, **최소값은 0으로 바닥 고정(clamp)**.

---

### 최종 점수 반환

```c
    return cnt;
}
```

## 3) main의 입력으로 실제 계산해보기

A:
`{2,0,0,0,0,0,1,1,0,0}`
B:
`{0,0,0,0,2,2,0,2,2,2}`

i별로 보자:

* i0: A=2, B=0
  func(0)=1, A(2) != 1, A!=B → else → cnt=0 유지
* i1: A=0, B=0 같음 → 변화 없음 (0)
* i2: 0==0 → (0)
* i3: 0==0 → (0)
* i4: A=0, B=2
  func(2)=0 → A==0 맞음 → +3 → cnt=3
* i5: A=0, B=2
  func(2)=0 → +3 → cnt=6
* i6: A=1, B=0
  func(0)=1 → +3 → cnt=9
* i7: A=1, B=2
  func(2)=0 → A(1) !=0 → else → -1 → cnt=8
* i8: A=0, B=2
  func(2)=0 → +3 → cnt=11
* i9: A=0, B=2
  func(2)=0 → +3 → cnt=14

✅ 최종 출력: `14`

## ⚠️ 코드에서 주의할 점

1. `recordB_len`을 안 쓰고 있음

* 길이가 다르면 out-of-bounds 위험.
* 보통은 `min(recordA_len, recordB_len)`까지만 돌거나, 애초에 같다는 가정이면 assert/검증 필요.

2. `func()`가 0/1/2 이외 값이 들어오면 전부 0 취급

* 입력이 항상 0/1/2라고 가정한 코드.
