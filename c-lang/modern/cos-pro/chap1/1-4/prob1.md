좋다 😎
알고리즘에서 `snprintf`를 **자연스럽게 쓰도록 훈련용 문제**를 단계별로 내줄게.

(전부 C 기준, `stdio.h` 사용)

---

# 🟢 Level 1 — 기본 포맷 연습

## 1️⃣ 정수 자리수 맞추기

정수 `n`이 주어질 때, 항상 **5자리 문자열**로 만들기.

* 부족한 앞자리는 `0`으로 채운다.

### 예시

```
입력: 42
출력: "00042"

입력: 12345
출력: "12345"
```

힌트:

```
%05d
```

---

## 2️⃣ 부호 포함 출력

정수 `n`이 주어질 때 항상 부호를 포함해서 출력하라.

### 예시

```
입력: 10
출력: "+10"

입력: -7
출력: "-7"
```

힌트:

```
%+d
```

---

# 🟡 Level 2 — 알고리즘 스타일 문제

## 3️⃣ 날짜 포맷 만들기

연, 월, 일이 주어진다.

```
2026 2 5
```

→ `"2026-02-05"` 형태로 반환

### 조건

* 월, 일은 항상 두 자리

---

## 4️⃣ 시:분:초 만들기

초 단위 정수 `total`이 주어진다.

```
3661
```

→ `"01:01:01"`

---

## 5️⃣ 좌표 문자열 만들기

정수 x, y가 주어진다.

```
x = -3, y = 10
```

→ `"( -3 , 10 )"` 형태 출력

공백까지 정확히 맞출 것.

---

# 🟠 Level 3 — 문자열 조합 응용

## 6️⃣ 큰 수 + 쉼표 넣기

정수 `123456789` → `"123,456,789"`

조건:

* `snprintf` 사용
* 직접 3자리마다 쉼표 삽입

---

## 7️⃣ 진법 변환 출력

정수 n을

* 10진수
* 16진수
* 8진수

형태로 하나의 문자열에 출력

### 예시

```
입력: 255
출력: "dec:255 hex:ff oct:377"
```

힌트:

```
%d %x %o
```

---

## 8️⃣ 소수점 자리 고정

double 값이 주어진다.

```
3.141592
```

→ `"3.14"`

---

# 🔴 Level 4 — 알고리즘에서 자주 나오는 트릭

## 9️⃣ 숫자 이어붙이기

정수 A, B가 주어진다.

```
A = 12
B = 34
```

→ `"1234"` → 정수 1234 반환

---

## 🔟 팰린드롬 검사 문자열 만들기

정수 n이 주어진다.

* n과 reverse(n)을 이어붙인 문자열을 만들어라.

```
입력: 123
→ "123321"
```

---

# 🔥 보너스 (실전 알고리즘 감각)

## 11️⃣ 숫자 정렬 키 만들기

정수 배열이 있다.

```
[3, 30, 34, 5, 9]
```

각 숫자를 문자열로 변환해 이어붙였을 때 가장 큰 수가 되도록 정렬하려 한다.

이때 비교용 문자열을 `snprintf`로 만들어라.

힌트:

```
"ab" vs "ba" 비교
```

(이건 프로그래머스 "가장 큰 수" 유형)

---

# 🎯 훈련 팁

`snprintf`에서 자주 쓰는 포맷 정리:

| 포맷     | 의미        |
| ------ | --------- |
| `%d`   | int       |
| `%lld` | long long |
| `%f`   | double    |
| `%.2f` | 소수점 2자리   |
| `%05d` | 0채우기      |
| `%+d`  | 부호 포함     |
| `%x`   | 16진수      |
| `%o`   | 8진수       |
