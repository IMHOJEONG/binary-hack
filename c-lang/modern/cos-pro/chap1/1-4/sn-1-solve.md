# ✅ 1번 문제

```c
int n = 42;
char result[10];
snprintf(result, sizeof(result), "%05d", n);
```

✔ 정답 맞음 💯

### 결과

```
"00042"
```

### 왜 맞냐면

* `%05d`

  * `0` → 빈칸을 0으로 채움
  * `5` → 전체 자리수 5
  * `d` → 정수

---

# ❌ 2번 문제 (오류 있음)

```c
snprintf(result, sizeof(result), "+d", n);
```

여기 문제는 👇

```
"+d"
```

→ 이건 그냥 문자열 `+d`야
→ 포맷 지정자가 아님

---

# ✅ 정답은 이렇게

```c
snprintf(result, sizeof(result), "%+d", n);
```

### 왜 `%+d`?

* `%` → 포맷 시작
* `+` → 항상 부호 포함
* `d` → 정수

---

# 🔎 결과 비교

```c
n = 10  → "+10"
n = -7  → "-7"
```

---

# 🔥 자주 헷갈리는 포맷 옵션 정리

| 포맷     | 의미        |
| ------ | --------- |
| `%d`   | 기본 정수     |
| `%+d`  | 부호 항상 포함  |
| `% d`  | 양수는 앞에 공백 |
| `%05d` | 0으로 채움    |
| `%-5d` | 왼쪽 정렬     |

---

# 💡 실전 팁

코딩테스트에서 부호 포함은 은근 자주 나온다.

예:

```
"+00123"
```

이런 것도 가능:

```c
snprintf(buf, sizeof(buf), "%+06d", n);
```
