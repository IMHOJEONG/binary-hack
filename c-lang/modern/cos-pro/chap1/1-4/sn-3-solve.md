# 🔥 6번 — 3자리마다 쉼표 넣기

### ❌ 지금 코드 문제

```c
sscanf(v, "%d%d%d", one, two, three)
```

문제점:

1. `&` 빠짐 ❌
2. `"123456789"`은 공백이 없어서 `%d%d%d`로 분리 안 됨 ❌
3. 이 문제는 “3자리씩 나누기”라서 `sscanf`로는 적절하지 않음 ❌

---

## ✅ 올바른 해결 방식

이 문제는 **문자열 길이를 기준으로 직접 나눠야 함**

### 풀이 예시 (정석)

```c
char v[32] = "123456789";
char result[32];

int len = strlen(v);
int comma_count = (len - 1) / 3;

int idx = 0;
int r = 0;

for (int i = 0; i < len; i++) {
    result[r++] = v[i];

    if ((len - i - 1) % 3 == 0 && i != len - 1) {
        result[r++] = ',';
    }
}

result[r] = '\0';
```

### 결과

```
123,456,789
```

✔ 이 문제는 `snprintf`만으로는 해결 불가
✔ 문자열 조작 문제

# 🔥 7번 — 진법 변환

이건 거의 맞았다 👍

```c
int v = 255;
char result[32];

snprintf(result, sizeof(result),
    "dec:%d hex:%x oct:%o",
    v, v, v
);
```

### 결과

```
dec:255 hex:ff oct:377
```

✔ 완벽함

# 🔥 8번 — 소수점 자리 고정

### ❌ 현재 코드 문제

```c
double v = 3.141592   // 세미콜론 없음 ❌
"%2f"                 // 의미 다름 ❌
```

---

### `%2f` 의미

* 최소 너비 2
* 소수점 자리 지정 아님

---

### ✅ 정답

```c
double v = 3.141592;
char result[32];

snprintf(result, sizeof(result),
    "%.2f",
    v
);
```

### 결과

```
3.14
```
