이 코드는 **1번~N번 후보**에 대한 투표 목록 `votes[]`를 받아서, **최다 득표 후보(들)의 번호를 배열로 반환**하는 코드야. (동점이면 여러 명 반환)

아래에서 위에서부터 흐름대로 설명해줄게.

---

## solution 함수

### 1) 후보별 득표수 세기

```c
int vote_counter[11] = {0};
```

* 후보 번호를 인덱스로 쓰는 카운터 배열.
* 크기가 11인 이유: 후보가 최대 10명이라고 가정하고 `1~10`을 쓰기 위해(0번은 안 씀).
* 전부 0으로 초기화됨.

```c
for (int i = 0; i < votes_len; i++) {
    vote_counter[votes[i]] += 1;
}
```

* votes 배열을 한 번 훑으면서
* 예: votes[i]가 5면 `vote_counter[5]++`
* 결과적으로 `vote_counter[k]` = k번 후보 득표수

⚠️ 주의: votes[i]가 1~N 범위를 벗어나면 배열 범위를 벗어나서 위험.

---

### 2) 최다 득표수(max_val)와 그 후보 수(cnt) 구하기

```c
int max_val = 0;
int cnt = 0;
```

* `max_val`: 현재까지의 최다 득표수
* `cnt`: 최다 득표를 기록한 후보가 몇 명인지

```c
for (int i = 1; i <= N; i++) {
    if (max_val < vote_counter[i]) {
        max_val = vote_counter[i];
        cnt = 1;
    }
    else if(max_val == vote_counter[i]){
        cnt += 1;
    }
}
```

* 후보 1~N을 돌면서

  * 더 큰 득표수를 발견하면 `max_val` 갱신, 동점 후보 수는 다시 1로 리셋
  * 득표수가 `max_val`와 같으면 동점 후보 수 `cnt++`

---

### 3) 결과 배열 동적 할당

```c
int* answer = (int*)malloc(sizeof(int)*cnt);
for(int i = 0; i < cnt; i++)
    answer[i] = 0;
```

* 최다 득표 후보가 `cnt`명 있으니 그만큼 int 배열을 만든다.
* 이후 채우니까 사실 0 초기화는 필수는 아니지만, 안전/디버깅용 느낌.

---

### 4) 최다 득표 후보 번호를 answer에 담기

```c
for (int i = 1, idx = 0; i <= N; i++){
    if (vote_counter[i] == max_val) {
        answer[idx] = i;
        idx += 1;
    }
}
```

* 다시 후보 1~N을 보면서
* 득표수가 `max_val`인 후보 번호 i를 결과 배열에 차례대로 넣음

---

### 5) 반환

```c
return answer;
```

* malloc 메모리이므로 호출자가 `free()` 해야 메모리 누수 없음.

---

## main에서의 테스트 케이스 결과

### 케이스 1

```c
N1 = 5
votes1 = {1,5,4,3,2,5,2,5,5,4}
```

득표수:

* 1: 1표
* 2: 2표
* 3: 1표
* 4: 2표
* 5: 4표  ✅ 최다

→ 반환: `[5]`

main이 `for(i<1)`로 1개만 출력하니까 `[5]`가 맞게 출력됨.

---

### 케이스 2

```c
N2 = 4
votes2 = {1,3,2,3,2}
```

득표수:

* 1: 1표
* 2: 2표 ✅
* 3: 2표 ✅
* 4: 0표

최다 득표는 2표, 동점 후보는 2명(2번, 3번)

→ 반환: `[2, 3]`

main이 `for(i<2)`로 2개 출력하므로 `[2,3]` 출력됨.

---

## ⚠️ 이 코드에서 실무적으로 아쉬운 점 3가지

1. `vote_counter[11]` 고정

* N이 10을 넘으면 터짐.
  → `malloc(N+1)`로 동적 배열로 만드는 게 더 안전.

2. 반환 배열 길이를 함께 반환하지 않음

* 호출자는 `cnt`를 모르면 몇 개가 들어있는지 알 수 없음.
  지금 main은 “문제에서 정해준 개수”를 아는 것처럼 하드코딩해서 출력 중.

보통은:

* `answer_len`을 out parameter로 주거나
* 구조체로 `{int* arr; int len;}` 반환하거나
* 마지막에 -1 sentinel을 넣는 방식 등을 씀.

3. `free(ret1)`, `free(ret2)`가 없음 → 메모리 누수

---

원하면 이 함수를 **`(int* answer, int* answer_len)` 형태로 길이까지 같이 반환**하도록 깔끔하게 리팩토링한 버전도 바로 만들어줄게.
